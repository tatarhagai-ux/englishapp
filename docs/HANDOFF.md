# Speakwise: סיכום מעבר לשיחה חדשה

עודכן ב-26.10.2026 (ערב). מי שקורא: Claude בשיחה החדשה. המשתמש הוא חגי תתר. תקרא את כל הקובץ לפני שמתחילים.

## 0. מצב עצירה

האפליקציה עובדת באוויר עם מפתחות אמיתיים, מודל נבחר וסנכרון אוטומטי. כל מה ש-חגי אישר (נקודות 1 עד 6: סנכרון, תוכנית 12 שבועות, מסך Today והסברים, דוח שבועי, רצף עם ימי מנוחה, תגיות רמה) נבנה ונבדק. מה שנשאר פתוח: "מסלולים" בתרגול, שחגי ביקש להשאיר להמשך.

## 1. מי חגי ומה הוא רוצה

- חגי, דובר עברית, משרת בצה"ל בתפקיד משרדי עם זמן פנוי. מבין אנגלית טוב (בערך B2), מדבר פחות (בערך B1+), נתקע ומחפש מילים.
- אין יעד קשיח. אולי טיסה לחו"ל או חיפוש עבודה בעוד שנה. רוצה לחזק דיבור, הבנה ואוצר מילים, להידחף למילים קשות יותר ולראות שיפור.
- קצב: 5 פעמים בשבוע, 10 עד 12 דקות. לא נעול: ביום פנוי מתקדם יותר. תזכורת ב-17:30.
- חשוב לו: זול ואיכותי. Azure ו-Whisper: לא, עולה כסף.

### העדפות כתיבה (חובה)
- לענות **בעברית**. השם בעברית: חגי תתר.
- טון ישיר וטבעי, בלי "leverage", "optimize", "game-changing", "dive into".
- **בלי מקף ארוך (em dash)** בשום פלט.

## 2. כללי עבודה שהוא קבע

- **מפתחות API לא נכנסים לצ'אט ולא לקוד.** רק משתני סביבה ב-Vercel. לא מדפיסים סודות או טוקנים בפלט (גם לא את טוקן הסנכרון).
- לא מעלים קוד אדום. לפני כל push: `npm run check`, `npm run format:check`, `npx playwright test`.
- שליחה החוצה, מחיקה או הוצאה כספית: לשאול קודם.
- **מיזוג:** חגי לא רוצה להיכנס ל-GitHub כל פעם. Claude פותח PR, מחכה ל-CI ירוק וממזג בעצמו.
- המשימה המתוזמנת (כל 5 שעות) כבויה. לא להפעיל מחדש.

## 4. מה בנוי (בקצרה)

Next.js 15, TypeScript strict, Tailwind v4, PWA, Vitest (252 בדיקות), Playwright (66 בדיקות, טלפון ומחשב), CI ירוק.

- **מודל:** `deepseek/deepseek-v4-flash` דרך OpenRouter, עם `reasoning: {enabled:false}`. נבדק מול חלופות: תפס 100% מהטעויות, 0% תיקונים מיותרים, מילה ראשונה תוך כ-0.4 שניות. חגי אישר שהוא טוב ומהיר.
- **Home = Today:** תוכנית 12 שבועות × 5 ימים (`content/plan.ts`). כל שבוע: נושא, מיקוד אחד, 8 מילים "מעל היומיומי" עם עברית ודוגמה. התקדמות נגזרת מהשיחות (`planDay` על השיחה, נספר כשיש דוח). מילה ששימשה פעמיים "שלו". בדיקת דיבור בסוף שבועות 4, 8, 12.
- **Progress:** השבוע מול שבוע שעבר (שבוע מתחיל ביום ראשון), בדיקות דיבור להשוואה, "Words you own" מתוך 96. הרצף סולח על עד 2 ימי מנוחה ברצף.
- **Practice:** תרגול חופשי עם תגיות רמה (B1 / B1+ / B2), ובכל מסך "How it works".
- **מיקרופון:** לחיצה פותחת, לחיצה שנייה שולחת מיד. אחרי 3 סבבים ריקים המיקרופון נעצר ומחכה ללחיצה. כפתורי "Say it" מראים מתי המיקרופון באמת פתוח ומה נשמע. הצפצוף ואייקון המיקרופון בשורת הסטטוס באנדרואיד באים מכרום ומהמערכת, ואי אפשר לבטל אותם ב-Web Speech. חגי שם על שקט וזה בסדר לו.
- **סנכרון:** אוטומטי, בלי התחברות. השרת גוזר טוקן מ-`APP_SESSION_SECRET` (HMAC) ושומר דרך `/api/sync`. מסנכרן בפתיחה, אחרי שינוי, בחזרה לאפליקציה ובחזרה לרשת. בדיקה: `/api/diagnostics?token=<DIAG_TOKEN>&check=sync`.
- **עוד:** כפתור עדכון באפליקציה (`/api/version` מול `NEXT_PUBLIC_BUILD_ID`), מצב כהה/בהיר/מערכת (כהה כברירת מחדל), אייקון "Wave", תזכורת ביומן (17:30 כברירת מחדל), מצב הדגמה.

## 5. רעיונות להמשך

1. מסלולים בתרגול (חגי ביקש, להמשך).
2. לבדוק איתו אחרי שבוע של שימוש: האם התוכנית קשה מדי או קלה מדי, והאם מילות השבוע מתאימות.
3. תזכורת Web Push אמיתית (Supabase כבר מחובר).
4. Azure רק אם יחליט, לקולות טובים וציוני הגייה.

## 6. הערות טכניות שחסכו זמן

- להרים שרת בדיקה: `npm run build`, ואז `OPENROUTER_API_KEY=sk-or-dummy-1234567890 APP_ACCESS_CODE= npx next start -p 3200`. מפתח קצר מ-10 תווים גורם ל-500. לא להריץ `pkill` על next באותה פקודה (קוד 144), להרוג לפי PID.
- e2e: `E2E_PORT=31xx npx playwright test`. בלי מפתח השרת לא "ready", אז הכפתור ב-Home הוא "Finish setup".
- לא לחבר בדיקות עם `| tail` בתוך שרשרת `&&`, זה מסתיר כישלון.
- ה-proxy חוסם גישה ישירה ל-openrouter.ai, supabase.co ו-vercel.app. לאתר החי ניגשים דרך `web_fetch_vercel_url`.
- commit messages מסתיימים בשורות ה-attribution מהתזכורת של המערכת.
