# מדריך הקמה

המדריך עובר על כל החשבונות שהאפליקציה צריכה, לפי הסדר. הוא לוקח בערך 20 דקות. בסוף כל שלב אפשר לפתוח את המסך `/setup` באפליקציה ולבדוק שהשירות מסומן כמחובר.

> לא שולחים מפתחות בצ'אט ולא שומרים אותם בקוד. הם נכנסים רק ל-Vercel, למסך Environment Variables.

## 1. Vercel: להעלות את האפליקציה לאוויר

1. נכנסים ל-[vercel.com](https://vercel.com) ומתחברים עם GitHub.
2. לוחצים **Add New → Project**, ובוחרים את `tatarhagai-ux/englishapp`.
3. לפני שלוחצים Deploy, פותחים את **Environment Variables** ומוסיפים שני משתנים:
   - `APP_ACCESS_CODE`: קוד כניסה שתבחר, לפחות 6 תווים. איתו תיכנס לאפליקציה.
   - `APP_SESSION_SECRET`: רצף אקראי של 40 תווים לפחות. אפשר פשוט להקליד אותיות ומספרים בלי סדר. לא צריך לזכור אותו.
4. לוחצים **Deploy**. אחרי דקה בערך מקבלים קישור.

בלי שני המשתנים האלה, ה-API של האפליקציה נשאר סגור ב-Vercel. זה מכוון: כך אף אחד אחר לא יכול להשתמש בקרדיט שלך.

## 2. Azure Speech: קול, זיהוי דיבור והגייה (חינם)

1. נכנסים ל-[azure.microsoft.com/free](https://azure.microsoft.com/free) ופותחים חשבון. Azure מבקש כרטיס אשראי לאימות זהות, אבל בשכבה החינמית לא מחויבים.
2. ב-[Azure Portal](https://portal.azure.com) מחפשים **Speech service** ולוחצים **Create**.
3. ממלאים:
   - **Resource group**: יוצרים חדש, למשל `speakwise`.
   - **Region**: `West Europe`. זה האזור הקרוב לישראל עם כל היכולות, כולל הערכת הגייה.
   - **Name**: שם כלשהו, למשל `speakwise-speech`.
   - **Pricing tier**: **Free F0**. חשוב לבחור את זה.
4. **Review + create**, ואחר כך **Create**.
5. בתוך המשאב שנוצר פותחים **Keys and Endpoint** ומעתיקים:
   - את **KEY 1** למשתנה `AZURE_SPEECH_KEY`.
   - את **Location/Region** (למשל `westeurope`) למשתנה `AZURE_SPEECH_REGION`.

השכבה החינמית כוללת בכל חודש 5 שעות זיהוי דיבור וחצי מיליון תווים של הקראה. ב-15 דקות ביום זה מספיק בשפע.

## 3. OpenRouter: המוח של ה-tutor

1. נכנסים ל-[openrouter.ai](https://openrouter.ai) ונרשמים.
2. ב-**Credits** טוענים 10 דולר. ב-15 דקות ביום זה אמור להספיק לחודשיים עד שלושה.
3. ב-**Keys** לוחצים **Create Key** ומעתיקים אותו למשתנה `OPENROUTER_API_KEY`.
4. מומלץ להגדיר למפתח **credit limit** של 15 דולר, כרשת ביטחון נוספת מעבר לתקרה שבתוך האפליקציה.

## 4. Supabase: זיכרון והתקדמות

השלב הזה נכנס בבנייה הבאה. אפשר כבר לפתוח פרויקט חינמי ב-[supabase.com](https://supabase.com), ואת החיבור נעשה ביחד.

## להוסיף משתנים אחרי שהאפליקציה כבר באוויר

ב-Vercel פותחים את הפרויקט, ואז **Settings → Environment Variables**. מוסיפים את המשתנה ומסמנים את Production ואת Preview. אחר כך פותחים **Deployments**, לוחצים על שלוש הנקודות ליד הגרסה האחרונה ובוחרים **Redeploy**. משתנים חדשים נכנסים לתוקף רק אחרי Redeploy.

## להתקין בטלפון

- **אייפון**: פותחים את הקישור ב-Safari, לוחצים על כפתור השיתוף ובוחרים **Add to Home Screen**.
- **אנדרואיד**: פותחים ב-Chrome, ובתפריט בוחרים **Install app**.

אחרי ההתקנה האפליקציה נפתחת כמו אפליקציה רגילה, בלי שורת כתובת.
